# YED-299 layer 1: mutation test of the ADR-9 guard (2026-11-20)

PRIVACY-LAYER EVIDENCE. It covers `spine_client.guard` / `_scan_pii` / `_scan_normalized` / `_declared_id` /
`_scanned_scalar` / `_walk_masked` / `domain_denylisted` with `EMAIL_RE`, `PHONE_RE`, `EMAIL_ALLOWLIST_RE`,
`FORBIDDEN_COLUMNS` and `ID_SHAPES`, plus `pii_normalize.canon` / `l3_form` / `heuristics` / `_isbn13` /
`_bare_digit_spans` / `has_pii` / `redact` and every module-level regex and table those use. Every probe below is
fictional: example.com / fakeco.test, NANP area code 555, Ofcom and ARCEP drama ranges, and all-zero subscriber numbers.

## Method

mutmut 3.x was installed into a scratch venv and dropped. It needs a `setup.cfg` and a pytest runner inside the
project, and it does not mutate inside regex literals, which is where most of this guard's logic lives. Instead a hand-rolled pass
(`ast` parse, one mutation, `ast.unparse`) ran on a scratch mirror of the three scripts. The unmutated unparse
must pass both selftests before any mutant runs.

Operators, by site count: AT_FORM 6, AT_SPELLING_RE 7, BARE_DIGITS 4, DOT_FORM 4, EMAIL_ALLOWLIST_RE 2, EMAIL_RE 5, FORBIDDEN_COLUMNS 6, ID_SHAPES 22, PHONE_RE 57, PROTECTED 19, SPACED_AT 2, SPACED_DOT 5, UTS46_DOTS 3, WORD_FORM 3, _bare_digit_spans 7, _declared_id 2, _isbn13 9, _scan_normalized 12, _scan_pii 10, _scanned_scalar 7, _walk_masked 4, canon 1, domain_denylisted 8, guard 23, has_pii 2, heuristics 1.
- Regex literals: drop one top-level alternative (`split_alternatives`); nudge each `{m,n}` lower bound by +/-1;
  drop each look-around group.
- Code: comparison swaps (`==`/`!=`, `<`/`<=`, `in`/`not in`, `is`/`is not`), `and`/`or`, drop `not`, negate each
  `if`, flip a boolean return, delete each `_refuse(...)` call, and int constant +1.
- Tables: drop each `FORBIDDEN_COLUMNS` member and each `UTS46_DOTS` key.

Survivors were triaged with an in-process differential probe (patch the mutant into the live modules, then compare
`guard()`, `PHONE_RE` alone, `EMAIL_RE` alone and `has_pii` over about 450 fictional candidates). Equivalence
claims were then checked by a 40k-sample random differential fuzz over phone, email, hex and fullwidth-dot
alphabets. The fuzz overturned one claim: the `ID_SHAPES['uuid']` group-length mutants first looked masked by
`PROTECTED`, but a malformed uuid in a declared `*_id` field would have been exempted. Those mutants now have cases.

Harness defect found and fixed mid-run: CPython's `.pyc` cache is keyed on source mtime + size, so a same-length
mutant written in the same second as the previous one imported stale bytecode. The first run's numbers were
discarded, and every run above uses `PYTHONDONTWRITEBYTECODE=1` with `__pycache__` cleared before each mutant.

Layer rule (privacy controls fail per layer, regardless of backstop): PHONE_RE / EMAIL_RE mutants are judged at the
regex alone, as the existing `_phone()` cases are, and not only through `guard()`. The bare-digit rule masks most
PHONE_RE weakenings at the `guard()` level.

## Real guard gaps found (NOT fixed here; reported as forks)

All of these pass every layer today (`guard()` returns the row). They need a decision because PHONE_RE / EMAIL_RE
are shared with the DB CHECK (migration 0025, `check_pii_regex_parity.py`):

| id | input shape (fictional) | why it passes |
|---|---|---|
| G1 | `call 555-123-0100x12`, `+44 20 7946 0958x12`, `Tel+44 20 7946 0958`, `Mob07700 900123` | every alternative's `(?![\w])` / `(?<![\w.+-])` treats a glued extension or label as part of a longer token; separators defeat the bare-digit rule |
| G2 | `+65 60000000`, `+33 639981234` | the intl alternative needs at least two groups after the country code; 8-9 digit blocks are under the bare-digit rule's 10 |
| G3 | `5 5 5 1 2 3 0 1 0 0`, `+4 4 2 0 7 9 4 6 0 9 5 8` | spaced-out digits: alternative 1 needs 3-3-4 groups, intl allows at most 5 groups, and no run reaches 10 |
| G4 | `dana@example. com` | SPACED_DOT needs whitespace before the dot; whitespace only after it is not folded |

Mutants #38, #40 (G2) and #186 (G4) are left alive on purpose: the only cases that kill them would pin the gap.
