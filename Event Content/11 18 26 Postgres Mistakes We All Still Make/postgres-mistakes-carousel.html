Three mistakes, one root

UPDATE writes a new row copy
Old copy = dead row
Vacuum may only remove rows no open transaction can see
Oldest open transaction sets the line (xmin horizon)
Idle transaction pins the line → bloat database-wide
Still holds a real connection, even behind a pooler
Deploy or failover: every client reconnects at once → connection storm
Bloat · idle in transaction · connection storms: the abstract’s three, as one chain.
