Two different things

Memory ≠ checkpoint

Checkpoint

One run
  • Where the agent is
  • What it's waiting on
  • Restored after a crash

Memory

Across runs
  • What it learned
  • Kept and corrected over time
  • Outlives any process
MongoDB ships both, side by side.
