MCP Release Party · NYC01 / 06
① Statelessness · before · 2025⁠-⁠11⁠-⁠25

Stateful: pinned to one instance

Sticky routing and a shared session store bridge every request. Any follow-up must return to the exact instance that holds your context — so you can't freely cycle the fleet.

Slide: Alex Hancock (Block / MCP)02 / 06
① Statelessness · after · 2026⁠-⁠07⁠-⁠28

Stateless: any instance, any request

Each request carries everything the server needs — no initialize no session. Drop a normal load balancer in front and autoscale by adding servers.

③ Tasks extension · long-running tool calls

A slow tool call becomes a handle
