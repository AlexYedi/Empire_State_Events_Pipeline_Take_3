A “don’t” can be worse than nothing

Spec values the agent re-typed into its dispatch. Lower is better. Opus, 5 runs per phrasing.

Jesse’s rule: cheap for mechanics, never for judgment.

CODE / CHEAP MODELmechanics
  • chunk the plan
  • dispatch one agent per task
  • run the scripts
  • route the verdicts
TOP MODELsix judgment calls
  • why a subagent is stuck
  • what a diff can’t prove
  • what each dispatch contains
  • review verdicts and severity
  • false-positive calls
  • knowing the plan itself is wrong
HUMANfour stops
  • irreversible or destructive
  • security-sensitive
  • side effects outside the work (merge, push, publish)
  • a plan so broken every path is a guess

Everything else: the agent decides and logs a Ruling (what · why · cost if wrong).

Per run, one test project (go-fractals), June config: ~$13. In the spec’s tests, a cheaper controller let a planted defect through in 4 of 5 runs.
