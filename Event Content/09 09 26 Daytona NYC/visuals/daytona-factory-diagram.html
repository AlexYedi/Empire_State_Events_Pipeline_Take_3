Deep dive · The factory

Your org's build line, run by agents

1
Connect your repos → prompt what you want built
↓
2
An orchestrator plans a DAG of tasks (it runs over days)
↓
3
Each task → a specialized agent in its own isolated sandbox
↓
4
Inside: clone → snapshot → build → must pass QA to finish
↓
5
Work converges into a PR — QA · security · adversarial review → you approve
Every sandbox is isolated and snapshotted — so runs are reproducible, and you pay for compute only while agents are actually building.
One PR she showed ran ~17,000 lines — already reviewed by QA + security agents before it reached her inbox.
Source: Obvious (obvious.ai) · Talk: Daria Shifrina · Daytona AI Builders NYC · Sep 2026
